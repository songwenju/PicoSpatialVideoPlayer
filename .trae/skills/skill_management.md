# 技能文档管理规范 (Skill Management)

为了确保项目技能文档的组织有序和可维护性，必须遵守以下存储规范：

## 核心规则
1. **统一目录**：所有新创建的技能文档（Skills）必须保存到项目根目录下的 `.trae/skills/` 目录中。
2. **文件格式**：技能文档必须使用 Markdown (`.md`) 格式。
3. **命名规范**：文件名应简明扼要地描述该技能，建议使用小写字母加下划线的命名方式（snake_case），例如 `naming_skills.md`。

## 目录结构
- `.trae/skills/`
  - `naming_skills.md` (命名规范)
  - `standard_commit.md` (提交规范)
  - `skill_management.md` (本规范文档)
  - ... (其他未来创建的技能)
